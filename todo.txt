~ tests/base/test.cpp:28 is testing the wrong idea.

Allocator correctness

align() is inverted (base_memory.cpp:5): it returns early for every power of two, so nothing is ever aligned. Change == 0 to != 0.
is_pow(0) returns true. It should be x && (x & (x - 1)) == 0.
arena_resize_block_align (base_arena.cpp) has several problems:
It returns MemArena * and should return void *.
The copy branch never returns new_memory and falls through to NULL.
MemSet(&arena->current_position, ...) overwrites the arena header.
The "last allocation" check uses previous_position, which is unaligned. Use old_mem + old_size == base + current_position.
